Day 2 – Data Processing Pipeline

Project Overview

This project focuses on building a data processing pipeline using Python. It processes transaction data from CSV files and prepares the data for further analysis.

Objectives

- Process transaction data using Python.
- Work with CSV files.
- Apply data cleaning and transformation techniques.
- Organize processed data for analysis.
- Practice version control using Git and GitHub.

Tools and Technologies

- Python
- Pandas
- CSV
- VS Code
- Git and GitHub

Project Structure

Data Processing Workflow

1. Load transaction data from CSV files.
2. Inspect the data.
3. Clean and transform the data.
4. Validate the processed data.
5. Save the results in the output directory.

Output

The "output/" directory is used to store the results generated by the data processing pipeline.

Key Learnings

- Python data processing.
- Working with CSV files.
- Data cleaning and transformation.
- Organizing a data engineering project.
- Using GitHub for project documentation and version control.
